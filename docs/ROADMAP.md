# BADAMOA 로드맵

각 Phase는 **설치해서 쓸 수 있는 상태**로 끝낸다. 설계 배경은 [ARCHITECTURE.md](ARCHITECTURE.md).

순서의 기준은 두 가지다. **가장 위험한 기술을 먼저 검증**하고(Windows·Linux 노드에서 torch 플러그인 환경이 깔끔하게 서는가),
**쓸모 있는 결과를 빨리** 낸다(라벨된 데이터로 YOLO를 학습해 모델을 등록하는 것이 첫 목표).
